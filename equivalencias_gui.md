# Equivalencia Interfaz-Terminal (CAP11_E05)
| Interfaz | Terminal | Ventaja | Limitacion |
|---|---|---|---|
| Commit to main | git commit | Seleccion visual | Menos automatizable |
| Push origin | git push | Evita errores de tipeo | Requiere GUI |
| Pull origin | git pull | Muestra avisos visuales | Menos opciones |
| Fetch origin | git fetch | Boton directo | Oculta referencias |
