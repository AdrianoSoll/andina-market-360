# Guia de Contribucion (CAP12_E05)
1. Ramas: Crear ramas desde main con prefijos feature/ o fix/.
2. Mensajes de commit: Usar formato descriptivo (feat:, fix:, docs:, test:).
3. Pruebas: Ejecutar python -m unittest discover -s tests antes de confirmar.
4. Seguridad: Prohibido enviar datos reales de clientes o secretos al repositorio.
5. Errores: Comunicar cualquier fallo abriendo un reporte en la seccion Issues.
