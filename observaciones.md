# Ficha de Observación de GitHub (CAP03_E01, CAP03_E02, CAP03_E03)
## 1. Áreas esenciales (CAP03_E01)
- Profile: Presenta la identidad del autor de Andina Market 360.
- Repositories: Aloja los archivos y carpetas del proyecto andina-market-360.
- Pull Requests: Permite revisar cambios en el script o el HTML antes de integrarlos a main.
- Issues: Registra tareas pendientes y errores en el cálculo de ventas.
- Search (Búsqueda): Permite localizar proyectos de referencia por lenguaje o tema.
Ruta de navegación hacia un repositorio público: Ir a la barra superior de búsqueda -> escribir propietario/repositorio (ej. github/docs) -> pulsar Enter y abrir en la lista Repositories.
## 2. Examen de un repositorio público: github/docs (CAP03_E02)
| Pestaña | Función observada | Diferencia respecto a Andina Market 360 |
|---|---|---|
| Code | Muestra archivos, carpetas, ramas y el README | Contiene miles de archivos frente a las 5 carpetas base de nuestro caso |
| Issues | Lista reportes de errores y mejoras de usuarios | Recibe reportes públicos globales; el nuestro es controlado y académico |
| Pull Requests | Propuestas de cambio esperando revisión | Requiere múltiples aprobaciones; en nuestro caso validamos con pruebas locales |
| Actions | Muestra flujos de automatización ejecutados | Tiene decenas de workflows; nuestro caso ejecuta unittest de Python |
| Settings | Configura reglas, seguridad y publicación | No es visible en repositorios ajenos; solo aparece en nuestro propio repositorio |
